# RPG System Control Plane

Этот каталог является надстройкой над существующей RPG-системой. Он не
заменяет записи, память, режимы НОВЫ или уже созданные файлы персонажа.

Главная задача слоя: дать агенту стабильный порядок работы, чтобы он не
переписывал факты, не смешивал дневник с выводами и не ломал симуляцию при
длинных задачах.

## Правило слоя

Существующие записи считаются источниками. Этот каталог содержит только:

- архитектуру работы;
- инварианты сохранности;
- протокол действий агента;
- циклы ревью;
- read-only инструменты проверки.

Если нужно изменить факт, рекорд, дневниковую запись, память, режим или
характер НОВЫ, агент должен остановиться и запросить явное подтверждение.

## Карта

- `INVARIANTS.md` — что нельзя ломать и где проходят границы.
- `RPG_ENGINE.md` — слои системы, источники истины и поток данных.
- `AGENT_PROTOCOL.md` — как агент должен выполнять задачи в этой папке.
- `REVIEW_LOOPS.md` — ежедневные, недельные и месячные циклы без правки записей.
- `tools/audit_rpg.py` — read-only аудит структуры и хешей файлов.

## Как использовать

Перед работой агент читает:

1. `INVARIANTS.md`
2. `RPG_ENGINE.md`
3. `AGENT_PROTOCOL.md`
4. нужные файлы из корня проекта

После работы агент запускает:

```powershell
python Vladimir_Kuplevatskyi/_rpg_system/tools/audit_rpg.py
```

Скрипт ничего не пишет на диск. Он только печатает состояние структуры.
