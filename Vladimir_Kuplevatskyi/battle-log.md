# Battle Log — Журнал вызовов и битв

Здесь фиксируются все серьёзные испытания: рекорды, вызовы смелости, социальные схватки, моральные решения.

---

## Формат записи

```md
## [ТИП] Название — Дата

### Контекст
- Состояние перед боем:
  - Энергия: /10
  - Настроение:
  - Бусты/баффы:
- Описание ситуации:

### Ход битвы
| Раунд | Действие | Результат | Энергия |
|-------|----------|-----------|---------|
| 1 | | | |
| 2 | | | |
| ... | | | |

### Итог
- Победа/поражение/ничья:
- XP получено:
- Рекорд побит?:
- Loot/разблокировано:

### Вывод
- Что понял:
- Что сделать иначе:
```

---

## Типы вызовов

| Тип | Описание | XP base | Пример |
|-----|----------|---------|--------|
| PHYS | Физический | 50 | Рекорд, тренировка на лимит |
| SOC | Социальный | 40 | Сложный разговор, переговоры |
| MENT | Ментальный | 30 | Учёба под давлением, экзамен |
| END | Выносливость | 60 | Долгая дистанция, многочасовой тест |
| FEAR | Вызов смелости | 100 | Выход из зоны комфорта |
| MORAL | Моральный выбор | 20 | Решение с последствиями |
| BOSS | Босс-файт | 200 | Особо крупное испытание |

# Дневник проигранных битв

Здесь — не победы. Здесь — моменты, когда сдался врагу. Это не стыд, а разведка боем. Каждое поражение анализируется и становится уроком.

Враги: лень, похоть, жрачка, соцсети, срыв протокола — любая форма капитуляции.

---

## Формат записи поражения

```md
## [ВРАГ] — Дата

### Что произошло
- Где и когда сдался:
- Триггер/причина:
- Как долго длилось:

### Разбор боя
- Как должен был поступить? (конкретное действие)
- Что помешало сделать правильный выбор?
- Какой навык/ресурс отсутствовал?

### Контрмера на будущее
- Что поставить на защиту? (техника, ритуал, правило)
- Режим повышенной готовности: сколько дней после срыва?

### Цена поражения
- Штраф к дисциплине:
- Откат прогресса (дней):
- Урок усвоен:
```
