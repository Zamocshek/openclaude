## Правила работы в симуляции

1. **Ежедневно**: минимум 3 квеста + пункт 14 (воздержание) обязателен
2. **Энергия**: 10 + (ур × 0.5). Каждое действие стоит 0–3 энергии
3. **Streak-множитель**: чем дольше streak, тем выше XP (×1.0 → ×5.0)
4. **Смерть**: 7 дней без единого действия → сброс XP и streak
5. **Карта мира**: перемещайся по зонам — каждая даёт свои бонусы
6. **Достижения**: открываются разблокируют постоянные баффы
