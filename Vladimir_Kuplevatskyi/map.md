# Карта цифрового мира — симуляция НОВЫ

Ты — Владимир Куплевацкий. Твоя цифровая копия перемещается по зонам этого мира.
Каждая зона даёт особые действия и бонусы.

```
                  ┌─────────────┐
                  │   Home Base  │
                  │  (старт дня) │
                  └──────┬──────┘
                         │
          ┌──────────────┼──────────────┐
          │              │              │
          ▼              ▼              ▼
   ┌──────────┐   ┌──────────┐   ┌──────────┐
   │Training   │   │  Study   │   │  Market  │
   │ Grounds   │   │   Hub    │   │ (MONEY)  │
   └─────┬─────┘   └────┬─────┘   └────┬─────┘
         │              │              │
         ▼              ▼              ▼
   ┌──────────┐   ┌──────────┐   ┌──────────┐
   │  Arena   │◄──┤  Temple  │   │  Hub of  │
   │(Доминация)│  │(Духовное)│   │Relations │
   └──────────┘   └──────────┘   └──────────┘
```

## Зоны

### 🏠 Home Base (домашняя база)
*Действия: отдых, планер, diary, inventory, трекинг.*

| Модификатор | Эффект |
|-------------|--------|
| Энергия | Восстановление +2/фаза |
| XP | ×1.0 |
| Особое | Единственное место, где можно провести полную ночь |

---

### 🏋️ Training Grounds (тренировочная арена)
*Действия: силовая, кардио, скакалка, отжимания, рекорды.*

| Модификатор | Эффект |
|-------------|--------|
| Энергия | -1 к стоимости тренировок |
| XP | ×1.5 для физических действий |
| Особое | Здесь ставятся рекорды. Каждый новый рекорд = +100 XP |
| Риск | Травма при попытке рекорда без разминки |

---

### 🧠 Study Hub (учебный центр)
*Действия: физика, математика, английский, биология.*

| Модификатор | Эффект |
|-------------|--------|
| Энергия | ×1.0 |
| XP | ×1.3 для интеллектуальных действий |
| Особое | +1 к интеллекту за каждые 10 часов изучения |
| Бонус | Изучение английского = открытие новых зон карты |

---

### 🏛️ Arena (арена доминации)
*Действия: социальные вызовы, переговоры, контр-атаки, квесты смелости.*

| Модификатор | Эффект |
|-------------|--------|
| Энергия | -2 к стоимости (высокое напряжение) |
| XP | ×2.0 для социальных действий |
| Особое | Единственное место, где растёт Доминация |
| Риск | Поражение = -50 XP + временный -1 к харизме |

---

### 💰 Market (рынок / MONEY)
*Действия: работа, арбитраж, проекты, финансы.*

| Модификатор | Эффект |
|-------------|--------|
| Энергия | ×1.0 |
| XP | ×1.2 |
| Особое | Доход × уровень навыка «Арбитраж» |
| Связь | Чем выше интеллект, тем выгоднее сделки |

---

### 🛐 Temple (храм / духовное)
*Действия: молитва, медитация, рефлексия, 12 шагов.*

| Модификатор | Эффект |
|-------------|--------|
| Энергия | +1 за действие (восстанавливает) |
| XP | ×1.0 |
| Особое | Усиление силы воли: каждое действие +0.5 к силе воли |
| Бонус | Молитва с утра = +1 энергия на весь день |

---

### 🤝 Hub of Relationships (центр отношений)
*Действия: социальные контакты, нетворкинг, гарем-менеджмент.*

| Модификатор | Эффект |
|-------------|--------|
| Энергия | ×1.0 |
| XP | ×1.5 для социальных действий |
| Особое | Каждый новый контакт = +1 к социальной сети |
| Связь | Чем выше харизма, тем быстрее растёт влияние |

---

### 🌲 Карпати (природа / восстановление)
*Действия: ходьба, грундинг, солнечная ванна, бег на длинные дистанции.*

| Модификатор | Эффект |
|-------------|--------|
| Энергия | +3 за визит |
| XP | ×1.0 |
| Особое | Снимает状态 Кризис |
| Бонус | +1 к выносливости за каждые 3 посещения |

---

### ⬛ The Void (пустота / неизведанное)
*Действия: исследование, риски, неизвестные квесты.*

| Модификатор | Эффект |
|-------------|--------|
| Энергия | -3 к стоимости |
| XP | ×3.0 (высокий риск) |
| Особое | Непредсказуемый результат. Может дать артефакт или штраф |
| Условие | Открывается только на уровне 5+ |

---

## Перемещение между зонами

| Маршрут | Время | Стоимость энергии |
|---------|-------|-------------------|
| Home Base ↔ Training Grounds | 5 мин | 0 |
| Home Base ↔ Study Hub | 5 мин | 0 |
| Home Base ↔ Market | 10 мин | 0 |
| Home Base ↔ Temple | 5 мин | 0 |
| Training Grounds ↔ Arena | 10 мин | 0 |
| Study Hub ↔ Temple | 5 мин | 0 |
| Market ↔ Hub of Relations | 10 мин | 0 |
| Любая ↔ Карпати | 30 мин | 1 |
| Любая ↔ The Void | 60 мин | 2 (только 5+ ур) |

Каждое перемещение занимает 1 действие, если время ≥ 10 мин.
