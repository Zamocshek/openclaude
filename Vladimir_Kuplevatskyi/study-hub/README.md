# Study Hub

Учебный центр персонажа. Здесь собираются материалы, планы и прогресс по ключевым направлениям.

## Разделы

- [physics](./physics/README.md) — физика.
- [mathematics](./mathematics/README.md) — математика.
- [english](./english/README.md) — английский.
- [biology](./biology/README.md) — биология, биохакинг и наука о теле.

## Правило работы

Каждая тема должна иметь:

- конкретную цель;
- источник или материал;
- практику;
- вывод;
- следующий шаг.
