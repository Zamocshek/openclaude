# Размышления

Папка для сортировки сильных мыслей, выводов, философии, стратегий и идей для симуляции.

## Категории

- Задачи и приоритеты.
- Решения и ошибки.
- Философия персонажа.
- Идеи для роста.
- Наблюдения о людях.
- Деньги и проекты.
- Тело, дисциплина и воля.
