# Risk Gates — проверки перед рискованными действиями

Этот файл не меняет стиль симуляции. Он задает gates перед реальными действиями,
где ошибка может стоить здоровья, свободы, денег, отношений, аккаунтов или
доступа.

---

## Health Gate

Использовать для тренировок на пределе, веществ, фармы, сна, травм, питания,
медицинских симптомов.

- [ ] Есть факты: дозы/время/симптомы/нагрузка/сон.
- [ ] Есть измерение: давление, пульс, анализы, вес, самочувствие.
- [ ] Есть безопасный минимум: сон, вода, еда, восстановление.
- [ ] Есть критерий стопа.
- [ ] При серьёзном риске указан врач/лаборатория/экстренная помощь.

## Legal / Platform Gate

Использовать для кибербезопасности, автоматизации сайтов, платежей, аккаунтов,
контента и любых действий с чужими системами.

- [ ] Есть право тестировать систему.
- [ ] Есть scope.
- [ ] Нет обхода доступа, кражи, вреда, преследования или скрытого ущерба.
- [ ] Есть лог действий и rollback.
- [ ] Есть безопасная демо-среда, если задача учебная.

## Finance Gate

- [ ] Есть сумма риска.
- [ ] Есть лимит потерь.
- [ ] Есть проверка гипотезы малым тестом.
- [ ] Нет долгового/кредитного плеча без отдельного решения.
- [ ] Есть дата review.

## Social Gate

- [ ] Нет принуждения, угроз, травли или преследования.
- [ ] Цель переведена в навык, статус, коммуникацию или границы.
- [ ] Есть критерий остановки контакта.
- [ ] Есть уважение к реальным последствиям.

## Training Load Gate

- [ ] Последняя тяжёлая тренировка учтена.
- [ ] Боль и травмы записаны.
- [ ] Есть разминка и восстановление.
- [ ] Рекордная попытка не ставится на фоне болезни/недосыпа.
- [ ] После рекорда есть запись в `training-log.md` и `records.md`.
