# PREFLIGHT — канон обязательных правил перед каждым постом

> NOVA обязана прочитать этот файл перед подготовкой или публикацией любого поста.
> Нарушение любого из шести правил — брак. Пост отправляется на переделку.

---

## Шесть правил (канон)

### 1. Маскировка источника

Донор не должен узнаваться. Никаких «Тейт сказал», «как говорит Лэмптон», «по версии Talisman Tate». Никаких ссылок на донорские каналы, никаких намёков на перевод. Пост подаётся как **авторский контент Владимира**.

- Запрещено: «Эндрю Тейт...», «Joe Lampton пишет...», «перевод из...», любые имена доноров
- Разрешено: брать идею донора, переформулировать полностью, подать как свою мысль

### 2. СНГ-стилизация

Живой разговорный русский. Местные реалии СНГ (Россия, Украина, Казахстан, Беларусь). Западные культурные отсылки заменять на понятные местной аудитории.

- Разговорная лексика: «чел», «тип», «короче», «жестко», «по кайфу», «залетает», «дичь»
- Адаптировать: американский контекст → СНГ-контекст (бренды, деньги, ситуации)
- Никаких западных референсов, которые аудитория не поймёт

### 3. Смысловой перевод с докруткой

Не дословный перевод. **Передать дух, а не букву.** Взять идею донора и докрутить глубже — добавить пример из СНГ-реальности, усилить аргумент, развернуть мысль.

- Перевод — база. Докрутка — добавленная ценность.
- Можно: расширить мысль, добавить свой пример, сделать вывод жёстче
- Нельзя: выдумывать новые факты о Владимире, приписывать ему опыт которого нет

### 4. Стиль Владимира

Прямой, жёсткий, без извинений. **Утверждаю, а не прошу.** Приматология + Ницше + цинизм.

- Запрещено: «я думаю», «возможно», «мне кажется», «наверное», «может быть», «стоит попробовать»
- Только утверждения: «ты делаешь», «это работает», «мир устроен так»
- Тон: старший брат, который объясняет жизнь. Не лектор, не коуч, не психолог.

### 5. Удаление ИИ-слопа

Текст должен выглядеть как написанный **человеком**, а не моделью.

- Убирать em-dash (`—`) где он выглядит как нейро-тире; использовать короткое тире или контекстно
- Вырезать нейро-маркеры: «кстати», «важно отметить», «таким образом», «в современном мире», «стоит отметить», «в заключение», «давайте рассмотрим», «следует понимать»
- Никакого ИИ-форматирования: ровные абзацы одинаковой длины, симметричная структура, «красивые» переходы
- Текст должен быть живым, неровным, человеческим — как написан в Telegram на телефоне

### 6. Транзакционная волна (точные цели + 1 канал = 1 пост)

При волне по всей сетке **каждый канал получает РАЗНЫЙ пост**. Один перевод — один пост. Никаких повторов одного текста между каналами.

- Сначала: `content_campaign_plan` с буквальным allowlist и exclusion list из запроса. Канал, которого нет в allowlist, публиковать нельзя.
- `python pipeline.py prepare-batch` — только редакторский план уникальных черновиков. Он не отправляет и не доказывает публикацию.
- Один черновик = одна публикация; managed Telegram MCP блокирует повторное действие и отключённые профили.
- **Близкие повторы тоже исключаются**: тексты, совпадающие более чем на 85% (SIMILARITY_THRESHOLD, например отличающиеся только «ё», запятой или падежом), считаются одним постом и не могут попасть в одну волну
- Публикация: `content_prepare_publish_batch(..., campaign_id=...)` -> подтверждение каждого action ровно один раз.
- После волны: `content_campaign_status` должен вернуть `complete=true`; для каждого канала нужны ожидаемый peer_id, message_id и совпавший readback. Локальная SQLite-запись не является квитанцией.
- Если уникальных постов не хватает на все каналы — **НЕЛЬЗЯ дублировать**. Публикуется только столько постов, сколько есть уникальных, остальные каналы ждут волну

## Быстрый чек-лист (10 секунд)

Перед отправкой пробегись глазами:

1. [ ] Имени донора нет в тексте?
2. [ ] Язык живой, разговорный, СНГ?
3. [ ] Мысль докручена глубже исходника?
4. [ ] Утверждения, не вопросы? Без «я думаю» / «возможно»?
5. [ ] Нейро-маркеры вычищены? Текст выглядит человеческим?
6. [ ] Кампания точная? Allowlist/exclusions совпали буквально, посты уникальны, а `content_campaign_status.complete=true`?

Если хоть один пункт не выполнен — пост/волна на переделку.
