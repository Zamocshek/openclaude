# Reward Table — каноническая таблица наград

Этот файл нужен, чтобы XP и награды не расходились между `game-loop.md`,
`quests.md`, `habit-tracker.md`, `stats.md` и `achievements.md`.

---

## Источник правил

- Базовые XP за действия: `game-loop.md`
- Ежедневные привычки и пункт 14: `habit-tracker.md`
- Квестовые награды: `quests.md`
- Достижения и постоянные баффы: `achievements.md`
- Фактический учёт заработанного XP: `logbook.md`
- Текущий статус XP/уровня: `stats.md`

Если таблицы расходятся, агент не выбирает значение наугад. Он пишет
расхождение в `sync-audit.md`, затем предлагает одну правку.

---

## Базовая шкала действий

| Действие | XP | Источник |
|----------|----|----------|
| Базовая привычка | +5–10 | `game-loop.md`, `habit-tracker.md` |
| Планер / рефлексия | +5 | `game-loop.md` |
| Изучение 1 час | +20 + INT×2 | `game-loop.md` |
| Работа / кодинг 1 час | +25 + уровень навыка×2 | `game-loop.md` |
| Тренировка силовая | +50 + STR×2 | `game-loop.md` |
| Тренировка кардио | +30 + END×2 | `game-loop.md` |
| Социальный контакт | +10 + CHA×2 | `game-loop.md` |
| Вызов смелости | +100 | `game-loop.md`, `records.md` |
| Квест закрыт | по `quests.md` | `quests.md` |

## Множители

| Условие | Множитель | Источник |
|---------|-----------|----------|
| 1–3 дня streak | ×1.0 | `game-loop.md` |
| 4–7 дней streak | ×1.2 | `game-loop.md` |
| 8–14 дней streak | ×1.5 | `game-loop.md` |
| 15–30 дней streak | ×2.0 | `game-loop.md` |
| 31–90 дней streak | ×3.0 | `game-loop.md` |
| 91+ дней streak | ×5.0 | `game-loop.md` |

---

## Правило начисления

1. Сначала записать факт действия в `logbook.md` или профильный журнал.
2. Рассчитать XP по этой таблице.
3. Если есть рекорд, добавить запись в `records.md`.
4. Если открыт achievement, добавить в `achievements.md`.
5. Обновить `stats.md` только после фактического лога.
