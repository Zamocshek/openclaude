# Планер — управление днём в симуляции

## Дневной бюджет

```
─────────────────────────────────────
Фазы:    Утро (2) | День (2) | Вечер (1)
Энергия: ____/10
Streak:  ×____
─────────────────────────────────────
```

---

## Шаблон дня

```md

- [ ]
```
