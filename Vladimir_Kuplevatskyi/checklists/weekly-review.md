# Weekly Review — недельная сверка

## Вход

- `logbook.md`
- `planner.md`
- `goals.md`
- `battle-log.md`
- `pattern-register.md`
- `stats.md`

## Процедура

1. Подсчитать XP недели.
2. Проверить streak.
3. Закрыть выполненные квесты.
4. Перенести незавершенные квесты или удалить из активного внимания.
5. Найти главный повторяющийся провал.
6. Добавить одну системную контрмеру.
7. Выбрать 1 фокус недели и до 3 целей.

## Выход

- обновленный недельный блок в `planner.md`;
- строка в недельном журнале `logbook.md`;
- при необходимости запись в `pattern-register.md`;
- короткий список задач на следующую неделю.
