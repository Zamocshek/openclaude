# Daily Runbook — ежедневный запуск

## Утро

1. Прочитать `CONTROL_PANEL.md`.
2. Прочитать `planner.md`, `quests.md`, `stats.md`.
3. Выбрать:
   - 1 главную цель;
   - 3 действия;
   - обязательный пункт 14;
   - одну контрмеру против главного риска дня.
4. Если день рискованный — открыть `risk-gates.md`.

## 15:00 Check

- [ ] Выполнено хотя бы 1 действие?
- [ ] Энергия не ниже 4/10?
- [ ] Есть риск срыва/слива дня?
- [ ] Нужно уменьшить план до минимума?
- [ ] Что делаем следующим одним шагом?

## Вечер

1. `diary.md`: нарратив дня.
2. `logbook.md`: таблица фактов.
3. `stats.md`: только подтвержденные изменения.
4. `battle-log.md`: если был провал.
5. `skill-log.md`: если был прирост.
6. `pattern-register.md`: если повторился класс ошибки.

## Минимальный вечерний ответ агента

```text
День закрыт:
- сделано:
- XP:

- главный урок:
- следующий первый шаг:
```
